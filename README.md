# Text Sending Web 📱

A simple website for sending text from one device to another without any authentication.

## Features

- Type or paste text on one device
- Generate a shareable link
- Open the link on another device
- Copy the text directly

## How to Use

1. Open the website on your first device
2. Type or paste your text in the textarea
3. Click "Send Text" to generate a shareable link
4. Copy the link and open it on your second device
5. The text will appear automatically - just copy it!

## Deployment

### Deploy to Vercel

1. Push your code to GitHub
2. Go to [Vercel](https://vercel.com) and import your repository
3. Click "Deploy" - no configuration needed!
4. Your site will be live in seconds

### Or use these commands:

```bash
# Install Vercel CLI
npm install -g vercel

# Deploy
vercel
```

## Tech Stack

- Pure HTML, CSS, JavaScript
- No backend required
- No databases
- Works on any static hosting (Vercel, Netlify, GitHub Pages, etc.)

## Why This Exists

When you have text on one mobile device and need to transfer it to another device where WhatsApp, Telegram, or other messaging apps don't work, this simple tool makes it easy to share text via a web link.
